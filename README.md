# UNSW-NB15 Intrusion Detection System (XGBoost + SMOTE)

This project trains binary and multi-class IDS models using the UNSW-NB15 dataset.
Features:
✓ SMOTE for imbalance
✓ XGBoost Classifier
✓ Multi-class predictions (10 attack types)
✓ Saved model + scaler + metadata
✓ Custom packet predictor script
